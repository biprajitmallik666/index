Project overview

About Chinese Learner

An interactive beginner-friendly tool for exploring basic Mandarin vocabulary.

Project objective

The objective of this project is to provide a simple digital learning platform that helps beginners explore common English-to-Chinese word mappings, view Pinyin romanization and practise basic Chinese number vocabulary through interactive flashcards.


Main features

  • English word and phrase lookup using a built-in dictionary.
  • Chinese Hanzi and Pinyin output.
  • 101 number flashcards covering zero to one hundred.
  • Reveal, previous and next flashcard controls.
  • Chinese character audio through browser text-to-speech, where supported.
  • Responsive layout for desktop and mobile screens.

Technologies used

  • HTML — page structure.
  • CSS — layout, styling and responsiveness.
  • JavaScript — dictionary lookup and flashcard interaction.
  • Web Speech API — text-to-speech pronunciation.

Important note

The translator is a predefined dictionary-based prototype, not a full sentence translation service. Audio availability and voice quality depend on the browser and installed Chinese voices.
